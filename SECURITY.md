## 🔒 Reporting a Vulnerability

We take the security of OmniKB and its users seriously.

If you believe you have found a security vulnerability in OmniKB, please **do not** open a public issue. Instead, report it privately to the repository maintainer:

- **Maintainer**: Ash ([@ashhstr](https://github.com/ashhstr))
- **Security Contact**: Via GitHub Security Advisory on the repository

### What to Include:
- A description of the issue and its potential impact.
- Steps or a minimal reproduction script to demonstrate the vulnerability.
- Any suggested fixes or mitigations.

We will acknowledge receipt within 48 hours and work on a prompt resolution.
